## 三、各里程碑立项卡

### M19 成片品质与品牌化

- **性质与来源**：M18 后评审最大缺口集群（后期成片品质的"品牌化精细度"）+ P0 快赢前二项；来源见 §一 A 组
- **拟定范围**：
  1. **字幕样式配置化**（快赢）——样式参数（字体 / 字号 / 主色 / 描边 / 背景 / 位置）项目级默认 + run 级覆盖；落点对齐 M11 `compose-config` / `run.input._compose` 先例；ffmpeg-merge 按分支开关改造（**无配置 = 现行为逐字不变**，对齐 M11 兼容纪律）
  2. **品牌水印 / Logo**（快赢）——overlay 滤镜（位置 / 透明度 / 尺寸 / 边距）；项目级品牌配置（settings 或平台级通用表，spec 论证落点）
  3. **片头片尾**——pre-roll / post-roll 资产拼接（concat 链扩展；与 M11 BGM / 转场链叠加兼容，总时长语义显式）
  4. **per-shot 音效 SFX**——每镜音效资产绑定（工作台绑定入口 + 上传通道）+ 合成期逐镜混音（对齐 M11 lines 时机链；无绑定 = 现行为）
  5. **成片多画幅输出**——一份 compose 多比例导出（16:9 / 9:16 / 1:1；crop 或 pad 策略选择；复用合成参数快照）
  6. **素材页批量生成**——多选实体批量排队（对齐 M13 批量润色交互模式：串行 ≤N、失败收集不阻断、`recordLlmUsage` / 用量记账）
  7. **角色 states 变体出图接线**——states 变体在生成时注入（出图链；M13 已完成 states 入库与列表透出，本次接注入端）
  8. **声音克隆**——能力声明制扩展（适配器能力位 + 供应商实现如阿里云 CosyVoice 系；无能力供应商置灰降级）
- **依赖**：无前置依赖；ffmpeg-merge / compose-config / 适配器能力声明制（M11 / M13 / M16 先例）齐备
- **红线初核**：不改引擎；ffmpeg-merge 按分支开关改造（M7 / M11 先例，无特性路径 filter 逐字节一致）；不新增体裁专属表（品牌配置落点 spec 论证）；零新依赖优先
- **建议验收方向**：字幕样式矩阵快照 + 白字默认零漂移对照；水印 / 片头尾真实合成目检（ffprobe 时长断言）；SFX 混音 dB 留痕；多画幅三比例 ffprobe 断言；states 变体出图目检 + 注入日志；批量生成用量对账；声音克隆能力位矩阵 + 供应商实测（不可得则登记降级）

### M20 运营自动化与复盘闭环

- **性质与来源**：M18 后评审运营集群 + roadmap Backlog（定时调度 / 批量成本统计 / CSV 分析）+ M4 review 局限转 Backlog + M14 §8 排产日历；来源见 §一 B 组
- **拟定范围**：
  1. **排产日历 / 批量运行计划**——项目 / 剧集级计划表（时点触发 + 与 batches / series 联动展示）；轻量自研调度器（**红线内**：计划表 + 幂等触发，非重型引擎，spec 论证边界）
  2. **发布数据回采系统化**——publications 增强：批量导入（表格 / 剪贴板）、同口径趋势视图（views / interactions）、回填提醒；改善"M4 登记 API 全手工"现状
  3. **发布 A/B 测试**——同内容多变体 / 多标题发布分组标记 + 效果对比视图（复用 publications 表 + 分组维度）
  4. **成本预算熔断与告警**——项目 / 月度预算设置 + run 预检拦截（M18 run-preview 定价链升级为闸门前置）+ 超阈告警
  5. **平台级成本聚合与 provider 用量**——跨项目聚合面板（usage 已有 → 维度拆解 / 时间窗 / provider 对比）
  6. **复盘数据 CSV 分析**——复盘视图增强（趋势 / 对比基线 / CSV 导出分析）
  7. **导出包平台化定制**——按平台导出规格预设（命名 / 比例 / 时长 / 水印组合；与 M19 多画幅 / 水印联动）
- **依赖**：M14 series / episodes、M4 publications / usage / batches 已在位；M19 多画幅有利联动但不强依赖
- **红线初核**："不引重型编排 / 任务引擎"红线——排产为轻量自研调度（spec 阶段论证）；新增表均为平台级通用表（对齐 M8 `style_presets` / M14 `series` 先例）
- **建议验收方向**：排产触发留痕（计划 → run 创建链）+ 幂等重触发 + 停用恢复；回采导入对账矩阵；A/B 分组视图 DOM；预算熔断拦截矩阵（预估超限 409 / 告警）；聚合口径与 usage 同源对拍

### M21 工作台体验（检索·通知·键盘流）

- **性质与来源**：M18 后评审工作台集群（无全局搜索 / 无长任务通知 / tags 有 API 无 UI）+ 快赢清单后三项 + roadmap Backlog（键盘流 / 并行上限）+ M14 §8 参数热调；来源见 §一 C 组
- **拟定范围**：
  1. **全局搜索**（快赢）——统一搜索端点（跨项目 / 运行 / 资产 / 实体 / 画布 / 文本资产 / 发布）+ 搜索 UI；分阶段：关键词检索（结构化列）→ 语义混合（复用 bge-small 本地向量，embedding 不可用时降级关键词）
  2. **长任务浏览器通知**（快赢）——Notification API + 权限引导 + run 终态 / 闸门到达 / 批量完成推送（Socket.IO 事件链已有）
  3. **资产 / 项目 tags UI**（快赢）——tags 编辑 / 筛选 / 批量打标；projects.tags 空置列启用
  4. **键盘流 / 命令面板**——全局快捷键体系 + 命令面板（搜索 / 跳转 / 触发动作）
  5. **Gate diff 审阅**（快赢）——闸门确认前产物对比（版本 diff / 并排对照；降低盲签风险）
  6. **多开任务并行上限**——跨任务并发配置上收全局（对齐 batch `max_concurrent` 既有语义）
  7. **集级参数运行中热调**——受限语义（仅未执行任务生效；追加式留痕，不破"快照即证据"）
