  - 途中发现（实测驱动）：本机 libass 的 **force_style 逐字段覆盖所有 Style 行**（非仅 Default，与 spec 假设不符）——实验锤定 numpad 映射本身标准（1-3 底/4-6 中/7-9 顶），但 force_style 会把具名组字号/落位打平回主样式毁掉分层。正解：多 Style 启用时各路烧录**省略 force_style**（args.ts `assLayered` 分支），Default 行改由 `defaultCfg`（合并主样式）全量承接（`assStyleRow('Default', cfg…, forceFontSize)`），缺省链逐字节零 diff 不变；UI/spec 承诺面已同步。
