# agencys-content-studio M6 实施计划（参考图驱动生成：定妆照参考链 + 首帧图生视频）

> **归档戳（2026-09-30）**：本计划已执行完毕，落笔即冻结仅作决策留痕（非待办）。覆盖关系查 [索引](../README.md)；现状以 docs/milestones.md 为准。

> 执行方式见文末 Handoff。步骤用 checkbox（`- [ ]`）跟踪。工程约束：不新增 action / 不新增 DB 表列 / 不改引擎（engine.ts / refs.ts / loader.ts）/ 不改路由 / 不改 Web / 不改 ffmpeg-merge；模板与提示词 version+1 向后兼容；全链宽容降级不为失败（semantics 见 spec §3.7）。

**Goal:** 打通「已生成图像资产 → 后续生成请求」的参考图通道为全自动链——①图片侧：ai_image 把角色定妆照（characters.refAssetIds）转 data URI 注入文生图请求；②视频侧：ai_video 消费 gen_frames 首帧图（shotId 匹配）驱动 i2v。落地 M5 spec §1.3 遗留接力（「待参考图通道扩展后接力」）。

**上游规格:** `docs/superpowers/specs/2026-09-12-agencys-content-studio-m6-design.md`。spec 中留待实施决策的点，本 plan 已全部定死（见下方"决策定死项"）；若实现中与 spec 文字冲突，以本 plan 为准并回写 spec 注记。

**Tech Stack:** TypeScript（Node 20+ / tsx）；drizzle-orm + SQLite；YAML 模板 + md 提示词外置；data URI 内联（本地单机无公网图床）；探针对齐 probe-m2a/m3/m4 传统（隔离临时库）。

**范围外（M6 明确不做，勿顺手）：** 镜头级工作台 / 尾帧接力链 / 公网图床 / 图片压缩管线 / 场景道具参考图 / `@图片N` 语法跨家统一 / 严格报错模式（不支持即降级 + 日志）。

## 决策定死项（实现前必读，全部已核实）

1. **能力判定时点**：ai_image / ai_video 主函数**入队前** resolve 一次端点（`resolveEndpoint` + `getImageAdapter` / `getVideoAdapter`，try/catch 失败 → `'none'`），结果经 cfg 传入 `runOneTask`；执行阶段不再 resolve（避免二次 DB 查询与行为漂移）。
2. **快照口径**：`refUsed` / `firstFrameAssetId` 在入队循环写入 `gen_tasks.params`（params 唯一写点）；执行阶段实际注入量与快照的差异（本地文件读失败等罕见场景）只体现在日志。
3. **data URI 转换时机**：`assetToDataUri` 在执行阶段（请求构建前）做、带 step 级缓存（`Map<number,string>`，同图多镜 base64 只算一次）；**shotId → assetId 匹配**在入队前做（`buildFirstFrameIndex`，需读资产行）。
4. **宽容语义依赖（已核实，勿重复验证）**：`ctx.assetIdsOf` 对 undefined/null → `[]`（context.ts:74-76）；被 when 跳过的步骤为终态、`steps.x.assets` 解析为 `[]`（refs.ts 注释专为互斥分支保障）；compose 的 images/motion_clips 互斥由 ffmpeg-merge 硬校验兜底 → `gen_frames` 独立步骤绕开。
5. **openai 系图片三家**（openai / siliconflow / pollinations）只需在 openai-image.ts 声明一次 `referenceImages = 'none'`（两个子类仅 override provider 名，capability 继承）。
6. **能力声明与实现同步落地**：Task 2 只声明"已就绪组 + none 组"；volcengine / qwen / wan-image 的 `'base64'` 声明与其注入实现（Task 3）同任务完成；volcengine-video 同理（Task 6）。任一步完成后声明与行为一致（探针可断言）。

  - `export const MAX_REF_IMAGE_BYTES = 8 * 1024 * 1024`
  - `export async function assetToDataUri(assetId: number, cache?: Map<number, string>): Promise<string>`
    - cache 命中 → 直接返回

    - 返回 `data:${mime};base64,${Buffer.toString('base64')}`；成功写 cache
  - 注释说明调用方契约：**「明确提供了图但抛错 → 调用方跳过该图 + 记日志，不使任务失败」**
