========================================
  百工工作室（便携版）使用说明
========================================

【这是什么】
一个装在你电脑上的内容创作工具，用浏览器操作。
不需要安装任何软件，解压即用。

【三步开始】
1. 双击「启动.bat」，会弹出一个黑色窗口，并自动打开浏览器
   （没自动打开的话，手动访问窗口里写的地址，形如 http://127.0.0.1:3001）
2. 第一次使用，先点网页里的「AI 配置」，填入你的 API Key（见下方说明）
3. 回到首页开始创作

【API Key 怎么拿（以 DeepSeek 为例，约 2 分钟）】
1. 浏览器打开 https://platform.deepseek.com ，注册/登录
2. 左侧菜单「API Keys」→「创建 API Key」→ 复制保存（只显示一次）
3. 回到百工工作室网页 →「AI 配置」→ 文本生成 → 选 DeepSeek →
   新建实例 → 粘贴 Key → 点「测试连接」显示通过即可
※ 也可以用 SiliconFlow、火山引擎、阿里云等其他平台，方法类似
※ Key 相当于钱包钥匙：用了多少算多少，请只填自己的，不要告诉别人

【日常使用】
· 启动：双击「启动.bat」，等浏览器打开
· 退出：直接关掉那个黑色窗口（或窗口里按 Ctrl+C）
· 黑色窗口使用期间不要关闭，关了网页就打不开了
· 再次双击「启动.bat」可以重新打开

【你的数据都在哪】
全部在本文件夹里，不联网上传：
· data\        你的数据库和配置（API Key 存在这里）
· workspace\   你创建的项目和生成的作品
想备份或换电脑：整个文件夹拷走即可
想重置成全新状态：关掉程序，删掉 data 和 workspace 两个文件夹再启动

【常见问题】
· 提示端口被占用：程序会自动换端口，无需处理；若仍失败，
  关掉其他占用了 3001~3015 端口的程序再试
· 杀毒软件报警：本程序自带 ffmpeg 等多媒体处理组件，
  属正常现象，选择「允许/信任」即可
· 双击后窗口一闪而过：右键「启动.bat」→「编辑」看内容是否完整，
  或把黑色窗口截图发给给你软件的人
· 首次启动慢（约半分钟）：正在初始化数据库，属正常现象

【系统要求】
Windows 10/11（64 位）· 内存 8GB 以上 · 磁盘剩余 1GB 以上
